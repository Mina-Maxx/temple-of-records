# دليل النشر المجاني 100% بدون أي تكاليف شهرية (0$ شهرياً)
## The Temple of Records — Free Cloud Deployment

المشروع ده مبني بـ Node.js خالص وبدون أي مكتبات خارجية (Zero Dependencies)، وده بيخليه خفيف جداً ويشتغل على أي منصة استضافة سحابية مجانية بسلاسة.

---

## الطريقة الأولى (الأسهل والأشهر): الاستضافة على Render.com (مجاناً مدى الحياة)

موقع [Render.com](https://render.com) بيقدّم خطة مجانية دائمة (Free Web Service) فيها:
- **دومين مجاني محمي بشهادة SSL (HTTPS)** بصيغة: `https://your-name.onrender.com`.
- إمكانية ربط دومين خاص بيك مجاناً تماماً في أي وقت.
- تشغيل Node.js بدون أي سيرفرات أو لينكس أو إعدادات يدوية معقدة.

### خطوات الرفع خطوة بخطوة:

#### 1) ارفع الكود على GitHub (مستودع خاص Private)
1. افتح حسابك على [GitHub](https://github.com) واعمل New Repository سمّه مثلاً `temple-of-records` وخليه **Private** (عشان فلاجاتك وملفاتك تفضل خاصة بيك).
2. ارفع ملفات المشروع عليه من جهازك:
   ```bash
   git init
   git add .
   git commit -m "Initial commit v7"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/temple-of-records.git
   git push -u origin main
   ```

#### 2) أنشئ الخدمة على Render.com
1. سجّل دخول في [Render.com](https://render.com) باستخدام حساب GitHub بتاعك.
2. اضغط على زر **New +** ثم اختر **Web Service**.
3. اختر المستودع الخاص بك `temple-of-records`.
4. املأ البيانات البسيطة دي:
   - **Name:** `temple-of-records` (أو أي اسم تحبه لموقعك)
   - **Region:** Frankfurt (أقرب لمصر والدول العربية)
   - **Runtime:** `Node`
   - **Build Command:** اتركه فارغاً أو اكتب: `echo ok`
   - **Start Command:** اكتب: `node server/server.js`
   - **Instance Type:** اختر **Free** (0$/month).

#### 3) إعداد بيانات الأدمن السري (Environment Variables)
في نفس الصفحة، انزل لقسم **Environment Variables** وأضف المتغيرات دي:
- `ADMIN_USER`: اسم المستخدم الخاص بيك كأدمن (مثال: `mina`)
- `ADMIN_PASSWORD`: كلمة المرور الخاصة بك كأدمن (10 حروف أو أكثر، اختار باسورد طويل وعشوائي ولا تستخدم أي مثال مكتوب هنا)
- `TOR_HTTPS`: القيمة `1`

*(الخادم أول ما يشتغل هيتعرف على المتغيرات دي تلقائياً وينشئ حساب الأدمن الوحيد الخاص بيك فوراً بشكل آمن ومحمي بتشفير scrypt).*

5. اضغط **Create Web Service**.
6. في خلال دقيقة واحدة، الموقع هيكون شغال ولايف ومعاك رابط `https://temple-of-records-xxxx.onrender.com`!

## تجربة الزوار واللاعبين بعد التعديل

1. **اللاعبون العاديون:**
   - مفيش أي شاشات تسجيل دخول أو حسابات للاعبين.
   - الزائر يقدر يقرأ التحديات والمقالات مباشرة.
   - لما ييجي يحل أي تحدي، بيلاقي حقل: **اسمك أو لقبك** (مثلاً: "أحمد علي" أو "CyberFox") وحقل **الفلاج**.
   - الموقع بيحفظ اسمه في متصفحه تلقائياً عشان ميكتبهوش كل مرة.
   - لما يبعت الفلاج صح، بيظهر له: `فلاج صحيح! اتسجّل الحل باسم «اسم اللاعب» ✓`.
   - اسمه بيظهر في قائمة "أبطال حلّوا هذا التحدي" أسفل التحدي!

2. **أنت (المدير الوحيد):**
   - تدخل على: `https://your-app.onrender.com/admin/login.html`
   - تسجل دخول باسم المستخدم وكلمة المرور اللي حطيتهم في الـ Environment Variables.
   - في لوحة التحكم هتلاقي:
     * **اللاعبون:** قائمة بأسماء كل الأشخاص اللي حلوا التحديات ونقاطهم ومحاولاتهم.
     * **المحاولات:** كل محاولة اتكتبت وأي فلاج اتجرب واسم اللي جرب مع تقنيع الفلاج.
     * تحرير كامل للتحديات والمقالات والإعدادات والأدلة.

## نصيحة بخصوص وضع النوم في الخطة المجانية لـ Render (Spin-down)

الخطة المجانية لـ Render بتعمل Sleep للخدمة لو مفيش زيارات لمدة 15 دقيقة، وأول زائر بعدها بيستنى حوالي 30 ثانية لحد ما الموقع يصحى، وبعدها بيشتغل بسرعة فائقة.

**لو عايز الموقع يفضل صاحي 24/7 ومينامش أبداً مجاناً:**
1. افتح موقع مجاني زي [cron-job.org](https://cron-job.org) أو [UptimeRobot.com](https://uptimerobot.com).
2. اعمل حساب مجاني واطلب منه يفتح رابط موقعك `https://your-app.onrender.com` كل 10 دقائق.
3. بكده السيرفر هيفضل شغال على طول بدون نوم وبدون ما تدفع مليم واحد!

## الطريقة الثانية البديلة: الاستضافة على Koyeb (مجانية ولا تنام)

موقع [Koyeb.com](https://www.koyeb.com) بيوفر خدمة مجانية Nano Service دائمة (Always-On) ولا تدخل في وضع النوم:
1. اربط حساب GitHub.
2. اختر المستودع `temple-of-records`.
3. اضبط أمر التشغيل: `node server/server.js`.
4. اضبط الـ Environment Variables:
   - `ADMIN_USER` و `ADMIN_PASSWORD` و `TOR_HTTPS=1`.
5. اضغط Deploy.
