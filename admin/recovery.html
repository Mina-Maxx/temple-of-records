Account recovery

استعادة كلمة مرور المدير

لا يوجد استرداد بالبريد أو خدمة حسابات خارجية في هذا الخادم. لا ترسل كلمة مرورك لأحد.

إذا كنت ما زلت مسجّل الدخول، يمكنك تغيير كلمة المرور من الإعدادات باستخدام الكلمة الحالية.

إذا فقدت الوصول: أوقف الخادم، احتفظ بنسخة احتياطية خاصة، ثم شغّل الأمر المحلي أدناه وأعد تشغيل الخادم لإنشاء حساب جديد دون حذف المحتوى.

node server/reset-admin.cjs --confirm-local-reset

هذا الأمر يحذف اعتماد الأدمن والجلسات المحلية فقط، ولا يرسل أي بيانات للخارج.

Local administrator recovery

There is no email reset or external account service on this server. Never share your credentials.

If you are still signed in, update your password in Settings using the current password.

If locked out: stop the server, keep an offline backup, run the command below locally, then restart and complete first-run setup. Content and solves stay untouched.

node server/reset-admin.cjs --confirm-local-reset

This removes only the local admin credential and session hashes.
