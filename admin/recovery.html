Account recovery

لا يوجد استرداد بالبريد أو خدمة حسابات خارجية في النسخة المحلية. لا ترسل كلمة مرورك لأحد.

There is no email reset or external account service in this local build. Never send your password to anyone.

إذا كنت ما زلت مسجّل الدخول، يمكنك تغيير كلمة المرور من الإعدادات باستخدام الكلمة الحالية.

If still signed in, change it in Settings using the current password.

إذا فقدت الوصول: أوقف الخادم، احتفظ بنسخة احتياطية خاصة، ثم شغّل الأمر المحلي أدناه وأعد تشغيل الخادم. سيُنشئ الملف حسابا جديدا من شاشة الإعداد الأول دون حذف المحتوى.

If locked out: stop the server, keep a private backup, run the command below locally, then restart. Create a new admin from first-run setup. Content stays unchanged.

node server/reset-admin.cjs --confirm-local-reset

هذا الأمر يحذف اعتماد الأدمن والجلسات المحلية فقط. لا يرسل بريدا ولا يرفع أي بيانات.

It removes only the local admin credential and sessions. It sends no email and uploads nothing.
